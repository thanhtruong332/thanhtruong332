## About

Embedded Systems engineer (HCMUTE) focused on RISC-V CPU design and hardware security accelerators on FPGA.

- Designed **RISSP**, a from-scratch RV32I core with a *modular-execution* datapath — each instruction class runs on its own parallel hardware block
- Built and benchmarked **3 RISC-V SoCs** on ZedBoard sharing the same **AES-128 / SHA3-256 / RSA-2048** AXI4 accelerators, isolating microarchitecture as the only variable
- Derived an analytical model predicting the cycle gap between cores across 8 workloads to within **2 cycles**
